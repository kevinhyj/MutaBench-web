# Contribute a dataset

[Open a dataset proposal](https://github.com/kevinhyj/MutaBench-web/issues/new?template=dataset-proposal.md). Sign in to GitHub to submit it. You can follow proposals in the [public issue tracker](https://github.com/kevinhyj/MutaBench-web/issues).

Include a link to the dataset or its publication, its license or terms of use, and a short description of what was measured. For mutation-effect assays, describe how variants are identified, which reference was used, and what the reported values and units mean. If a field is unknown, mention it in the proposal.

The issue gives maintainers and contributors a public place to discuss the dataset and its fit for the benchmark before inclusion.
