What is MutaBench?

How well do general-purpose AI models and models trained on biological data predict what a mutation will do? MutaBench checks their predictions against real lab measurements.

See how the two model families perform across tasks.

Compare model results ↓

What the models get

Zero-shot. The models get the mutation question without any examples of measured effects.

Few-shot. The models also get measured effects for other mutations from the same experiment.

MutaBench holds back the measured effect of the test mutation and uses it to score the predictions.

    Method

    From molecular context to measured effects.

    General-purpose language models (LLMs) and biological foundation models (BioFMs) follow task-specific protocols, with query measurements reserved for independent evaluation.

    1. Keep each assay’s endpoint, score direction and query set fixed. Evaluate sequence, MSA, structure and joint evidence as separate conditions; standalone molecules use SMILES with or without computed 3D context.

    2. Zero-shot supplies the task context and query samples without measured examples. Few-shot adds known examples from the same assay, separate from the query set. Record the actual example count and mutation order.

    3. LLMs and BioFMs produce one score per query using their respective task-specific protocols. Keep each model’s input and scoring settings fixed within a comparison, save its predictions, and validate sample IDs, scores and completeness.

    4. Only the evaluator reads the query measurements. Report signed Spearman ρ for continuous endpoints and AUROC for binary ligand classification. Compare matched assay and query sets, with coverage and missing results reported separately.

    Protocol details: input conditions, few-shot splits and evaluation rounds

    Few-shot splits. Fixed-query comparisons and low-order-to-higher-order mutation tests are separate protocols. Examples can accumulate across mutation orders; the order limit is not the shot count. Main fixed-query runs use 250 queries, while small-pool complex pilots retain their own support and query sizes.

    Zero-shot inputs. Evidence availability and query size depend on the assay. ADMET uses the official test rows rather than a 250-sample subset. Its first-round result (CR1) and three-round score average (CR3) are reported separately.

    Multi-round feedback. This is a separate evaluation: only previously selected measurements become visible. Cumulative support size, query size and round count are recorded independently; hidden query labels remain excluded throughout.
